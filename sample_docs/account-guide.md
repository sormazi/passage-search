# Account recovery guide
If you lose the phone used for two-factor authentication, use one of your saved backup codes to sign in. Each recovery code can be used once. After regaining access, register a replacement authentication device and generate new backup codes. Store them in a secure place separate from your phone.

To change your password, open account settings and select Security. Passwords must contain at least twelve characters. A password manager can generate and store unique passwords. Never share a recovery code with someone claiming to be support.
